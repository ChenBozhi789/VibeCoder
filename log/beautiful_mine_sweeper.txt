  - As a player, I want to right-click a tile to place a flag, marking where I suspect a mine is.
  - As a player, I want to see a timer tracking how long I've been playing the current round.

      - **Mine:** Game Over state. All mines revealed. Timer stops.

  3. **Win Condition:** User reveals all non-mine cells. Game displays "You Win!" message. Timer stops.
  4. **Reset:** User clicks "New Game" or selects a difficulty. Board resets. Timer and counters reset.

  - **Cell States:** Hidden, Revealed (Number 0-8), Flagged.

  - Board state (2D array of objects).
