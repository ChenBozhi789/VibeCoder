  ## 2. Core Features

  ### 2.1 Difficulty Levels
  The app must support the following standard configurations:
  - **Beginner**: 9x9 grid, 10 mines.
  - **Intermediate**: 16x16 grid, 40 mines.
  - **Expert**: 30x16 grid, 99 mines.

  ### 2.2 Gameplay Mechanics
  - **Reveal Cell**: Left-click reveals a square.
  - **Flag Cell**: Right-click (or long press on mobile) flags a square as a mine. Toggles flag on/off.
  - **First Click Safe**: The first revealed cell must never be a mine. If the random generation places a mine
  there, it must be moved or the board regenerated.
  - **Flood Fill**: When a cell with 0 neighboring mines is revealed, all adjacent neighbors are automatically
  revealed recursively.
  - **Win Condition**: All non-mine cells are revealed.
  - **Lose Condition**: A mine is revealed.
  - **Timer**: Starts counting up in seconds upon the first interaction (click/flag). Stops on Win/Lose.
  - **Mine Counter**: Displays (Total Mines - Number of Flags Placed). Can go negative if too many flags are placed.
  - **Reset**: A button to restart the game with the current difficulty immediately.

  ### 2.3 Persistence
  - **Best Times**: Track the fastest time (in seconds) for each difficulty level.
  - **Last Difficulty**: Remember the user's last selected difficulty level between sessions.
  - Data should be persisted using browser LocalStorage.

  ### 2.4 User Interface
  - **Header**: Contains Mine Counter, Reset Button (emoji face commonly used), and Timer.
  - **Grid**: Centered, responsive grid of cells.
  - **Difficulty Selector**: Dropdown or buttons to switch modes.
  - **Responsive**: Board should scroll if it exceeds screen width, or scale appropriately on mobile devices.

  ## 3. Technical Constraints
